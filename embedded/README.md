# Embedded Integration

`main_gui_final_project_ready.c` is a selected team-project integration file
showing the command/message interface used between the CyBot and the GUI.

The full Code Composer Studio workspace is intentionally not included because it
contains course support libraries, starter files, IDE metadata, build output, and
many lab iterations that are not needed for a professional portfolio.

This file depends on project/course support headers that are intentionally omitted.
